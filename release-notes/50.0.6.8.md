## 本次更新

### 手机 / 车机 / 电视（Android）

- **节目来源不再显示「未知源」**：节目单刷新完成后，频道信息里的来源字段会同步更新；老数据里没有记录来源、且只配置了一个节目单源时，按这个唯一的源回填。配置了多个源时不猜测，确实没匹配到的频道才显示「未匹配」。
- **切到没有节目单的频道，不再显示上一个频道的节目**：之前从有节目单的频道切到没有节目单的频道，节目区会一直挂着上一个频道的节目；现在换台先把节目区置为「查询中 / 暂无节目单信息」，再按新频道的结果填充。已经有节目缓存的频道仍然直接显示，不会闪一下空白。
- **两个同名 CCTV-1 一眼就能分清**：之前只有频道列表给同名多路流加了分辨率后缀，其它地方仍是两个一模一样的名字。这次后缀统一覆盖到频道列表、侧栏、宫格、顶部频道信息、分屏标题、频道信息弹窗和节目单时间线的行名；没有分辨率信息时退回用频道号区分，不会再出现两条完全相同的名字。

### PC（Windows / Linux / macOS）

- **节目单时间线上的同名频道也能区分**：时间线左侧的频道行名同样带上分辨率后缀，与频道列表的显示口径保持一致。

直接安装覆盖即可；Android 与桌面端可以分别更新。
