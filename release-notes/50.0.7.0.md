### 修复

- 直播断流后不再永久停在「已暂停」，会自动重连，重连次数用完会明确提示播放失败。
- 同一次断流只算一次重连，一次网络抖动不会再消耗两次重连机会。
- 直播断流不再被当成点播正常结束，不会出现画面冻结却仍显示播放中。
- 退出全屏后左右浮层回到正确高度，恢复上次窗口位置时标题栏不会再跑到屏幕外。
- 直播无法拖动进度时，进度条不再可以点，并说明为什么不能拖。
- 音频调整打开时不再报错，均衡器可以正常使用。
- 特大字号和 110% 缩放下，底栏、节目简介与频道行不再互相压盖或被截断。
- 屏保现在能正常显示时钟、日期、频道与节目，窗口模式下也会触发。
- 文件关联指向已不存在的程序时会标记为失效，勾选保存会重写路径。
- 状态接口不再把还没校验的频道算成无效频道。
- Windows 上 HDR 直通重新生效，系统 HDR 状态也会记进日志。
- 双击文件打开后，不会再被上次播放的频道覆盖。
- 关于页不再把同一个版本号显示两行，并直接标注当前是否已是最新。
- 映射管理器把远程规则与自定义映射分开计数，不再混成一个数字。
- 音量百分比提示在独立窗口中也能看到，移开鼠标后自动消失。
- 图像调整对话框内容超高时可在内部滚动，底部提示与按钮始终可见。
- 图像调整对话框的配色会跟随当前主题。
- 音轨与字幕轨的菜单勾选与实际播放一致，切换后立即生效。
- 已开播的节目不再提示设置提醒成功，会说明为什么不能设。
- 换台前会保存按频道设置的音轨与字幕，删除频道时清除该地址的偏好。
- 服务端口被占用时不再误报「已启动」，失败会说明原因。
- 端口被占用时自动换用下一个可用端口，并显示实际使用的端口。
- 订阅源的增删改只在点保存后生效，取消不再改动配置，改地址保存后会重新下载。
- 节目详情区在切换主题后不再变成不透明实底。
- 打开几千条订阅的频道列表不再卡住上百秒，列表改为分批加载。
- 滚动到靠后的频道时，台标与评分不再整行缺失。
- 按 V 隐藏字幕后，从菜单选择字幕轨能正常显示画面。
- 音调滑块与快捷键现在真正可调，且变调不变速。
- 音频直通、跳帧与音画同步等选项恢复正常生效。
- 台标按显示尺寸解码，翻页和滚动时不再反复解码同一张图。
- 关闭窗口的确认弹窗默认停在「取消」，回车不会再误触最小化或退出。
- 回看时底栏状态显示「回看中」，不再沿用「播放中」。
- 节目详情里的回看标签改为悬停显示，不再挤占信息行。
- 重新打开节目单会定位到当前正在播放的节目，不再从最早的时间开始。
- 扫描频道的表单在放大缩放下不再溢出，宽度随界面自适应。
- 电视端玻璃卡片补上材质层次，焦点放大时边缘不再被裁掉。
- 玻璃描边不再是均匀一条线，受光面与内暗边有了明暗层次。
- 覆盖层玻璃的霜层更实，下面的画面不会再透上来干扰文字。
- 深色下安卓液态玻璃改为压暗配色，不再整片发白。
- 安卓 10 及以上系统也能显示玻璃底栏。
- 强制 TV 与平板模式下画面锁定横屏，不再跟随手机方向转动。
- 强制 TV 模式下竖屏内容按比例显示，不再被拉伸变形。
- 电视上的频道页签有了焦点描边和轻微放大。
- 播放器控件按实际播放区域缩放，分屏和电视上大小更合适。
- 电视横屏首页滚动更顺畅，滚动时不再反复重算背景光斑。
- 菜单打开时方向键由菜单接管，不再被播放器抢走。

### 新增

- 设置页拆分为「常规 / 播放设置 / 网络」三个页签。
- 安卓端设置列表同步按常规、播放设置、网络三组排列，与电脑端一致。
- 设置页底部新增「恢复默认」，保存后状态栏会提示已保存。
- 帮助菜单新增「检查更新」，手动检查会给出正在检查、已是最新或检查失败的结果。
- 新增 GitHub 加速代理开关与代理列表，更新、订阅、节目单和台标下载共用同一份设置。
- HTTP 服务设置并入「网络」页签，运行状态、监听地址与认证码常显。
- 服务监听地址默认只监听本机，设置里说明了两种地址的区别。
- 网络页新增流媒体请求设置，可填写代理、Referer、自定义请求头与 User-Agent。
- 网络设置标注了哪些项目切换频道后生效、哪些只作用于播放器。
- 播放设置页可直接调整循环模式、片头片尾跳过以及视频、音频、字幕核心参数。
- 界面语言、日志等级、颜色模式与视觉风格并入设置页对应分组。
- 节目提醒 30 秒后自动关闭，鼠标悬停时暂停，并新增「稍后提醒」与「不再提醒此节目」。
- Esc 改为退出全屏或收起浮层，停止播放改用 Shift+Esc。
- 页签上显示各分类的条目数。
- 音量滑块悬停或拖动时显示百分比。
- 画中画里补上静音按钮与音量滑块。
- 频道列表空态直接给出打开文件与从剪贴板导入订阅的主操作。
- 字幕样式面板新增实时预览，播放右键菜单按用途重新分组。
- 多画面补齐了空态引导与操作提示。
- 图像调整里标注了哪些项目是即时预览。
- 播放页方向键单击跳 15 秒，按住可加速快进快退，松手才提交一次。
- 播放失败会按原因给出可执行建议，本地代理失效时自动改直连。
- 断流后会先切换到同名的备用线路，换台成功即重置断流计数。
- 持续缓冲会自动降到更低分辨率的线路并给出提示。
- 手机上换台失败或持续缓冲时，同样会先切同频道的备用线路。
- 竖屏播放页手势分区：左侧调亮度、右侧调音量、中间换台，拖动时显示百分比。
- 搜索输入时先保留上一轮结果，避免结果闪空。
- 电视频道列表连按三次上键可回到顶部并聚焦第一条。
- 电视焦点缩放改为更自然的弹簧动画。
- 横屏首页背景光斑跟随当前台标的主色。
- 订阅刷新最多四路并发，状态栏汇总成功、为空、失败与超时的数量。
- 电视端新增只保留进度条的控制层，左右键调进度时不再铺开整条底栏。
- 强制 TV 与平板模式的退出弹窗新增「改回自动模式」，可直接切回手机布局。
- 安卓液态玻璃新增边缘折射开关，默认开启。
- 播放信息新增首帧耗时等诊断数据。

直接安装覆盖即可；Android 与桌面端可以分别更新。
