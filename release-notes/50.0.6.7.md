## 本次更新

### 手机 / 车机 / 电视（Android）

- **冷启动首个频道无声画不同步**：修复进入应用直接播第一个频道时出现「只有声音没画面」或音画不同步的问题；音频输出与视频尺寸初始化改为按顺序就绪，播放器不再在没准备好的状态下抢先开播。
- **硬解失败后可恢复**：切换硬解后立即记录本次选择，遇到驱动崩溃（如部分国产芯片）重启后不再反复尝试同一个坏硬解，而是直接回落到软解，不会再卡在「黑屏起不来」。
- **同名多路频道都能看到**：同一频道存在 1080P / 576P 等多路流时不再被当成重复项合并，列表里两路都在，名称后带分辨率后缀，可分别播放（例如 CCTV-1 综合 · 1080P 与 CCTV-1 综合 · 576P）。
- **频道列表首尾不再「无限循环」**：手机竖屏和车机分屏滚到第一条/最后一条会停住，不会从列表底部突然跳回顶部；电视用遥控器时保留一次从末项跳回首项的便利行为。
- **节目单（EPG）匹配更准**：改为按频道核心词匹配，避免「吴江/靖江/镇江 新闻综合」这类同名频道互相串台；完全没有节目单的频道显示「暂无节目信息」，界面不再空白或错位。同时治理了订阅源与节目单反复重载导致的卡顿。
- **车机分屏首页的节目单**：频道加载完成后自动补拉节目单，进入分屏首页不再出现只有频道、没有节目信息的情况。
- **大屏弹窗与遥控器操作**：车机分屏右上角的信息弹窗按横屏重排（两列字段、长地址整行、关闭按钮固定可见）；控制栏「更多」面板改为两列布局且不会被屏幕或控制栏裁掉；电视模式下新增「信息」「播放工具」入口，遥控器焦点可以进入、用方向键选择、按返回关闭，不再出现「一按就关」。
- **浅色主题可读性**：修复浅色模式下部分界面仍按深色绘制（整页发黑、浅色玻璃上白字看不清）的问题；手机竖屏的 MINI 播放条、信息页、节目单时间线在浅色下都清晰可读。
- **竖屏切台不再抖动**：视频下方那行编码/分辨率/帧率徽章固定高度，切台加载期间保持等位占位，整页不再上下跳动。

以上改动已在手机、车机、电视三台设备上逐项实测：首播正常出图、连切 12 次不断流、两路 CCTV-1 分别可播、无节目单频道显示正常、深浅色切换可读。

### Windows / Linux / macOS（桌面端）

- **老 CPU 可以正常启动**：numpy 固定到 2.3.5。numpy 2.4 及以上的官方 Windows 包以 x86-64-v2 指令集为基线，AMD K10 / Athlon II 这类老 CPU 一导入就报非法指令、程序直接起不来。降级后频谱/音频可视化在 numpy 不可用时自动关闭并提示范围，主功能不受影响。
- **老显卡不再黑屏**：启动时探测显卡是否支持 D3D11，不支持（如只有 D3D10.1 的老卡）自动改用 OpenGL 渲染，避免「有声音没画面」。
- **界面字号与缩放**：设置里新增「外观」页，可单独调字号档位和界面缩放，列表行高、图标、节目单时间线、各类弹窗都跟着同一档位走；不影响系统 DPI，不会出现放大后布局错位。
- **浅色主题**：桌面端浅色主题的文字与背景对比同步修正。

如果你是从旧版本升级，直接安装覆盖即可；Android 与桌面端可以分别更新。
